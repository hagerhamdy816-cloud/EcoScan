# EcoScan Backend ♻️

## Overview

EcoScan is an AI-powered waste recognition and recycling application designed to encourage responsible waste management through intelligent waste classification and user engagement.

This repository contains the backend of the EcoScan graduation project, developed using **ASP.NET Core Web API and C#**.

The backend provides the API layer for communication between the mobile application and the server-side components.

## Technologies Used

- **C#**
- **ASP.NET Core Web API**
- **Microsoft SQL Server**
- **RESTful APIs**

## Key Features

- Backend API development for the EcoScan mobile application.
- Database integration using Microsoft SQL Server.
- Server-side support for the application's waste recycling workflow.
- Integration support between the mobile application and backend services.

## System Overview

EcoScan combines multiple components:

- **Mobile Application:** Flutter
- **Backend:** ASP.NET Core Web API
- **Database:** Microsoft SQL Server
- **AI Model:** YOLO-based waste recognition
- **Smart Bin Prototype:** ESP32-based hardware integration

## Getting Started

### Prerequisites
